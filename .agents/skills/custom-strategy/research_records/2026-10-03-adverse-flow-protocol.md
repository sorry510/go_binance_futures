# AF1 adverse-flow acceptance experiment

Frozen before returns are inspected. This is an experiment, not a release.

- Mechanism: a closed 1h candle advances despite opposite aggressive taker turnover, then the next forming hour accepts beyond its high/low. This is a proxy for passive absorption, not proof of order-book absorption. It differs from the existing price-down/flow-up divergence, high-volume narrow-range and quiet same-direction-flow mechanisms.
- Keep v29C as the base. Diagnostic control AF0 adds only observed current-hour activity (`Amount[0] > 0`) to both entries to remove the known zero-activity signal case. It does not predict next-minute liquidity and does not repair the execution model.
- AF1 adds one separately attributed complementary family. Long: rising closed price/body with taker-buy ratio <=0.48; short: falling price/body with ratio >=0.52. Volume between 1 and 3 times the preceding 8-hour mean, 4h EMA20/50 direction, strong opposite daily trend exclusion, ATR scale and no-chase conditions. Entry valid only during the next hour's first 15 minutes.
- AF2 is a causal alignment control: identical to AF1 except taker direction follows price (>=0.52 long, <=0.48 short). Freeze both before replay; do not select a winner by relaxing thresholds.
- Each family has both entry directions and signal-confirmed close rules. Complement exits are bound to the exact project opening-rule hash; base exits remain v29C. Complement normal profit ROI>=8 plus momentum/volume reversal; loss ROI<=-5 plus structural or confirmed momentum failure; 24h timeout requires outer ROI gate and momentum failure. Sole ROI-only complement exception: catastrophic stop -12; base -20.
- Data and execution: 2022-09-01..2026-08-31 UTC, standard 1m project engine, checksum-verified canonical execution and indicators, repair version 20261003-v2. Initial equity 1000 per coin, margin 10% current cash, leverage8, fees0.0005 and5bps slippage each side, historical funding, outer profit/loss5/5.
- Development BTCUSDT,ETHUSDT,SOLUSDT,XRPUSDT; only if all declared development gates pass, frozen validation AAVEUSDT,ATOMUSDT,ETCUSDT,LINKUSDT after checking full-date eligibility. They have supplied no returns in this experiment. Previously inspected coins are not untouched holdout.
- Release requires each coin >=0.9/week over all1461calendar days, positive net after costs, no losing full-year window, cross-coin confirmation and fill-minute execution audit. A counterfactual requires full matching; existing-family ledger slices are descriptive.
- Preserve all portable candidates/controls in temp_strategy/20261003-adverse-flow; large results and disposable verification stay in the research cache. No App, config mutation, DB writes, assignments, production engine changes or repository test files.

AF0/AF1 fail every coin's frequency gate; AF1 improves ETH's four annual nets but BTC/SOL/XRP still have losing years. AF2 passes frequency but BTC/SOL have negative total net and every coin has a losing year. None is a release.

Empty-hash diagnostics exposed a current forward receiver gap; passing the diagnostic does not fix it. No production mutation was authorized or performed.
