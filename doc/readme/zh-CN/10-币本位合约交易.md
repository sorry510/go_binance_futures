# 10 · 币本位合约交易（COIN-M）

[返回中文 README](../../../README.md) · [English](../en/10-coin-m-futures.md) · [开发方案](../../trade/开发方案-CM-币本位合约交易-复刻现货精简版.md)

## 适用范围与状态

- **适用产品**：Binance COIN-M（DAPI）USD 反向永续合约，仅限 `contractType=PERPETUAL`。不支持季度交割、交割合约自动移仓。
- **源码范围**：CM-0～CM-7，包括币种/策略配置、独立订单和成交 Fill 账本、反向盈亏、DAPI 适配、私有 WS、STOP/TP Algo、复用现有 2 秒策略调度和四个独立页面。
- **当前验证**：Go/前端编译与离线 Fake/Mock/SQLite 测试。**未完成真实 MySQL 8 v27 迁移、Demo/Testnet 开平仓、私有 WS 和 Algo 现场验收，也未授权生产运行。**
- **风险边界**：如果部署新版后手动打开全局及逐币开仓开关，并通过币安凭证与策略前置检查，自动调度器**可能发送真实订单**。不能把“页面无手动按钮”等同于“自动交易不会发生”。

## 页面与开关

| 入口 | 实际功能 |
| --- | --- |
| 配置中心 → 币本位合约交易 | 唯一全局开仓开关 `coin_m_quant_enable`，数据库默认 `0` |
| 币本位交易 → 币本位交易 | 查询 PERPETUAL，设置每币 `delivery_symbols.enable`、USD 预算、杠杆、逐/全仓、止盈止损、LONG/SHORT/CLOSE 规则 |
| 币本位交易 → 币本位本地账户 | 只读 Managed 周期、订单、真实 Fill、按保证金币种分开的收益、可选 USD 参考估值和单独的签名钱包只读查询 |
| 币本位交易 → 策略模板 | 独立模板 CRUD、导入/导出、四种方向规则与技术指标；不与现货或 U 本位共用模板 ID |
| 币本位交易 → 仓位与受控交易 | 本地运行状态、Managed 周期、未结算订单及证据状态的只读观察；**不提供手动真实下单/撤单/平仓/归属按钮** |

全局开关、逐币开关**仅阻止新开仓**；已有 Managed 仓位及未结算订单仍需要恢复、维持保护单与平仓。关闭开关本身不会强平或取消保护单。

## DAPI 网络与凭证隔离

| 环境 | 选择条件 | 凭证 |
| --- | --- | --- |
| mainnet | `binance.testnet=false`，`BINANCE_COIN_M_ENVIRONMENT=mainnet`（默认） | 现有主网 Binance API Key/Secret |
| testnet | `binance.testnet=true`，`BINANCE_COIN_M_ENVIRONMENT=testnet`（默认） | `app.conf` 中的独立 testnet API Key/Secret |
| demo | `binance.testnet=true` 且 `BINANCE_COIN_M_ENVIRONMENT=demo` | `BINANCE_COIN_M_DEMO_API_KEY`、`BINANCE_COIN_M_DEMO_API_SECRET` |

- DAPI 与 U 本位 FAPI、现货 Spot API **不混用**。环境不匹配、签名凭证缺失或 WS 不就绪时拒绝新开仓；不自动回落主网。
- 不允许自动修改 UM/CM 共用的双向持仓模式，必须先人工核实账户的 LONG/SHORT 配置。
- 合约张数 = USD 面值预算 × 杠杆 ÷ 每张合约 USD 面值，再按交易所 MARKET LOT_SIZE/STEP_SIZE 取整；**不是 BTC/ETH 数量**。
- BTCUSD_PERP 需要 BTC 保证金，ETHUSD_PERP 需要 ETH 保证金；不会自动转换资产或划转。
- `/coin-m/runtime-status` 只读取本地数据库，不访问签名 DAPI；其中开关、已启用币数和未结算数量**不等于**私有 WS 连通、交易所余额足够或仓位已核实。

## 收益、成交与幂等

- LONG inverse PnL（保证金币）= 张数 × 合约面值 USD × (1/开仓价 − 1/标记/平仓价)。
- SHORT inverse PnL（保证金币）= 张数 × 合约面值 USD × (1/标记/平仓价 − 1/开仓价)。
- 已实现收益从拥有真实 trade ID 的 DAPI Fill 加总；未实现收益需要新鲜 DAPI 标记价格。缺失成交、成交方向/币种不匹配、标记价格无效时，不虚构完整总收益。
- 手续费按 `commission_asset` 分别列示，资金费无权威收入流水时不计入。BTC 与 ETH 保证金币盈亏不能直接相加。USD 仅供参考，不是实际结算资产。
- OPEN/CLOSE 使用唯一 clientOrderId、`position_id` 归属及 `(symbol,exchange_order_id,trade_id)` Fill 去重；超时或 429 等不确定情况优先核对原订单，不盲目重发。
- 自动开仓必须拥有可执行 STOP/TP 参数。规则、指标、`Profit/Loss/TickSize/Leverage` 在策略求值期间变化时丢弃旧信号，下一轮重新评估。已有 Managed 仓位退出优先于新开仓。

```bash

go test -count=5 -p=2 ./service/coinmexecution ./service/coinmquant ./feature/api/binance ./controllers
go vet ./service/coinmexecution ./service/coinmquant ./feature/api/binance ./controllers
```
