## 二、06-5 后端只读 API

| 方法 | 路径 | 实际功能 |
| --- | --- | --- |
| GET | `/spot-quant/positions?symbol=&status=&page=&limit=` | Spot 策略持仓分页 + **整个筛选结果**的按报价币分组收益摘要，不限本页 |
| GET | `/spot-quant/positions/:id` | 单仓位精确重算视图 + 该仓位全部关联 BUY/SELL 订单和 Fill + 数据复核异常 |
| GET | `/spot-quant/orders?position_id=&symbol=&status=&page=&limit=` | 本地 Spot 委托表独立分页与状态筛选，含 position_id / exchange_order_id / client_order_id |
| POST | `/spot-quant/positions/:id/rebuild` | **仅本地账本重算**，请求 JSON 必须 `{"confirm":true}`，服务端先做订单状态复核，不修改 Fill，不调用 Binance |

实现文件：

- `controllers/spot_quant_account.go` 和 `routers/router.go`：控制器与唯一 Spot 专用路由
- `service/spotledger/readmodel.go`：独立账本列表/详情/订单与跨页摘要
- `service/spotledger/query.go`：**默认精确 symbol 匹配供执行层使用**；仅 UI 传 `SymbolLike=true` 时允许 A-Z/0-9 字符模糊搜索；不允许 SQL 通配符
- `controllers/spot_quant_account_test.go` 和 `service/spotledger/readmodel_test.go`：异常入参与 SQL/财务行为测试

**价格/盈亏安全规则：**

1. 所有数量、成本价和已实现盈亏均由 06-3 的真实 Fill 重放核算。不能拿可人工修改的 `spot_managed_positions.realized_pnl` 当作权威值。
2. 当前价格只读本地 `spot_symbols.close + updateTime`，校验更新时间在最近 **5 分钟内**；无价格、坏价格或过期价格时 `has_mark_price=false`，活动仓位的 `total_pnl` 留空。绝不从 Futures 标记价格或账户 PositionRisk 获取数据。
3. 完全平仓且无剩余资产时即使没报价，未实现盈亏为 0；但第三资产手续费（例如 BNB）若未能折价，`fully_priced=false`，UI 不显示为完整净收益。
4. `summary` 根据**全部筛选匹配记录**统计，不仅当前分页。USDT、USDC、FDUSD 不做跨币算术相加；任何未折价资产手续费、错误账本或缺少行情会把该报价币的完整总收益标记为未知，不能冒充“最终净利润”。
5. 当 Fill/订单状态有矛盾时，详情标记 `needs_review`、显示原因，相关可变汇总字段不在页面显示为可信收益。修复按钮需要显式二次确认，且订单审查异常时禁止重算。
