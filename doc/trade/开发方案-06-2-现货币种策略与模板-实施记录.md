## 一、阶段范围与隔离原则

- 复刻合约交易的币种列表、分页、币种分组、置顶、技术指标和规则编辑的交互，但**独立使用现货数据**。
- 新现货量化状态仅保存 `spot_symbols.spot_quant_enabled`；不复用、不改写历史 `spot_symbols.enable`。
- 每币预算存 `spot_symbols.usdt`，单位是该币对应的**报价资产**（USDT、USDC 或 FDUSD），不是固定 USDT。保留现货的 `profit` / `loss` 等配置。
- 模板**只**读写 `spot_strategy_templates`；不调用 Futures 的 `strategy_templates`、`symbols`、合约仓位或资金接口。没有新建数据库表或改变 schema 版本。
- 新增的 Spot Quant 编辑 API 采用字段白名单，禁止批量编辑旧市场价格、现货监听开关、交易精度或 Futures 字段。
- Spot 策略规则只允许 `long` / `close_long`；`short` / `close_short` 无论启用与否都会被拒绝。币种激活前必须具备至少一条已启用的有效 LONG 入场规则。模板草稿可保存/导入未启用的规则，方便后续编辑。
- 全局开关仍由 06-1 的 `config.spot_quant_enable` 管理，默认 0；06-2 **没有订单处理或自动触发器**。

### 2.1 Spot 币种 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/spot-quant/symbols` | `page,limit,symbol,symbol_type,enable,pin,sort`，页大小上限 100 |
| GET | `/spot-quant/symbols/:id` | 读取现货币种详情、配置、Spot 最新缓存价格 |
| POST | `/spot-quant/symbols` | 添加币种，默认 `spot_quant_enabled=0`，不下单 |
| PUT | `/spot-quant/symbols/:id` | 仅编辑预算、止盈止损、置顶、指标、策略、现货量化启停 |
| PUT | `/spot-quant/symbols/batch` | 必须提供 `ids`，事务批量修改最多 500 个币种；可应用 Spot 独立模板 |
| PUT | `/spot-quant/symbols/enable/:flag` | 关闭所有现货量化币种；开启时仅激活已配置有效 LONG 入场规则的币种 |
| POST | `/spot-quant/symbols/:id/rule-test` | 使用本地 Spot 币种价格的模拟预览；不读取 Futures PositionRisk |

### 2.2 独立策略模板 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | `/spot-quant/strategy-templates` | 分页列表/新建草稿 |
| GET/PUT/DELETE | `/spot-quant/strategy-templates/:id` | 查看、更新、删除独立 Spot 模板 |
| POST | `/spot-quant/strategy-templates/import` | JSON 导入；同名更新，否则新建；允许未启用草稿 |
| POST | `/spot-quant/strategy-templates/rule-test` | 独立策略试算，标记模拟价格 |

**注意**：Expr 预览里的 `mode=synthetic` 仅代表在指定或默认价格下跑通了表达式，**不是实盘信号**。`mode=syntax_only` 表示对没有实际 Spot K 线/指标数据的表达式只能确认语法，不能确认布尔结果。订单扫描、真实指标行情计算、资金校验和真正 BUY/SELL 属后续 06-3/06-4，不能将本阶段预览当作可交易结果。
