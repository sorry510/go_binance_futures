## 三、安全不变量

1. Binance Spot 仅允许 `long` / `close_long`。模板保存与现货配置保存都拒绝任何 `short` / `close_short`，包括被禁用的做空规则；不提供合约专用计算或按钮。
2. 交易页配置不能绕过 `LiveOrdersApproved=false`、`spotRealOrderReleaseApproved=false` 与 `canAttestLiveFills=false`；真正资金写入、人工解冻和真实成交所有权仍 BLOCKED。
3. **不可伪造账户资产**：本地 Holding 不是 Spot 账户钱包余额；没有核验的数量/成本/手续费/PnL 空值或标不完整。页面不把 `reserved_qty` quote 预留当作 base 未成交量。
4. Spot 模板不指向 `strategy-templates`（Futures）API，防止不同市场规则交叉污染。localStorage 只保存配置样本，不保存 API key、签名或凭据。
5. S4 mode `contract_version=4` 检查保留，不匹配后端时拒绝读取和编辑；无后台模式切换按钮。
