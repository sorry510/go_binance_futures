# Binance Pool Merged-Mining Support Addition — Feasibility

Hypothesis: Binance Pool adding merged-mining reward support for a PoW asset could improve miner distribution/access and act as a positive catalyst (LONG).

Strict 2023-2024 official-title audit found only 4 actual new merged-mining support batches:
- Junkcoin (JKC) + Pepecoin (PEP);
- Luckycoin (LKY);
- Fractal Bitcoin (FB);
- LTC/DOGE/Bellscoin (BEL).

Only LTC/DOGE among these are mature same-name USD-M assets; more importantly the event family has only **4 independent batches**, below the minimum 5 before any market eligibility or return inspection.

Decision: **coverage blocked / freeze**. Do not include Pool promotions/system updates, split one batch into multiple independent events, or lower the batch gate.
