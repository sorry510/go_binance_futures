# Protocol

1. Source only official Binance CMS catalog 49.
2. Enumerate the complete catalog before any return inspection.
3. Candidate titles must describe a capped funding rate/cap-floor adjustment.
4. Exclude any event that simultaneously changes leverage, margin tiers, or funding settlement frequency.
5. Broad market-wide rule changes count as one batch, not one event per affected token.
6. Require at least 8 independent production-eligible events before defining a directional discovery test.
7. If coverage is below 8, stop without inspecting returns.
