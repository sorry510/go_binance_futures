# Binance Funding Cap/Floor Adjustment — Feasibility

Hypothesis: an isolated change in perpetual funding-rate cap/floor could alter the cost and persistence of one-sided leveraged crowding. This stage intentionally excludes announcements that simultaneously change leverage/margin tiers or funding settlement frequency, because those mechanisms are already separate researched families and would confound attribution.

Official Binance CMS catalog 49 (`Latest Binance News`) was exhaustively paginated: 4,436 articles, with 90 funding-related titles across 2021–2026.

For 2023–2024, nearly every capped-funding update is mixed with leverage/margin-tier changes and/or funding-frequency changes. The only clean standalone capped-funding-rate event found is OGNUSDT on 2023-10-01. The 2023-09-28 broad rule is not a token-specific independent event and also changes settlement frequency for selected contracts.

Decision: sample-size blocked before any return inspection. Do not reuse mixed leverage-tier announcements as a separate funding-cap alpha, and do not split one broad rule announcement into pseudo-independent token events.
