# KuCoin Deposit+Withdrawal Resumption -> Binance LONG — Feasibility

The preregistered mechanism was external transfer-channel reopening: a KuCoin announcement that explicitly restores both crypto deposits and withdrawals should restore cross-exchange arbitrage/liquidity, so the mapped Binance USD-M contract would be entered LONG at the next complete 1h open.

The complete KuCoin CMS search corpus for "Deposit and Withdrawal Services" contained 1,215 articles. In 2023-2024, 36 titles matched resumption/reopening wording. Mechanical classification found 35/36 were token swap/migration/rebranding completion announcements, which belong to the already-frozen corporate-action family. The only non-corporate-action item was PIX fiat deposit/withdrawal maintenance, with no crypto USD-M target.

Decision: **0 independent crypto resumption events; feasibility fails before return inspection**. Do not reuse corporate-action completions as synthetic resumption samples.
