# Binance Holder Airdrop Support → LONG — 2023-2024 Feasibility

Hypothesis: Binance's first announcement that it will support an external project's airdrop/distribution to holders of an existing token can create incremental holding demand before snapshot/entitlement, so the holder token direction is preregistered LONG.

Official CMS audit:
- Binance catalogId=49, complete 2023-2024 title census: 1,071 titles.
- 12 titles contain airdrop/distribution terminology.
- Frozen exclusions remove Launchpool/HODLer/Super Stake/Wallet promotional rewards, completion notices, stablecoin distributions, mining rewards, and generic reward-policy/platform announcements.
- Only **1 qualifying external holder-airdrop event** remains: Binance support for the Pepper (1000PEPPER) airdrop to CHZ holders.

The preregistered coverage gate requires >=8 events and >=8 unique holder tokens before production eligibility or any post-announcement return is read.

## Final result

Raw semantic coverage is **1 event / 1 holder token (CHZ)**. Coverage fails before market-data eligibility.

No >=2y USD-M eligibility check, QuoteVolume check, or post-event return was read.

Decision: **coverage blocked / freeze**. Do not merge Binance HODLer Airdrops, BNSOL Super Stake rewards, stablecoin compensation distributions, or cross-exchange airdrops to manufacture sample size.
