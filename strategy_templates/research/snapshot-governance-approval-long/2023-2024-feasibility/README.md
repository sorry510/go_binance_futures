# Snapshot Governance Approval → LONG — 2023-2024 Feasibility

Hypothesis: when a clean binary Snapshot governance proposal closes with an explicit positive option (For/Yes/Approve/Support) winning, the resolved governance uncertainty may act as a positive protocol-token catalyst.

The rule and coverage gate were frozen before any market return was read:
- exactly two choices;
- one clean positive and one clean negative label;
- positive score strictly greater than negative score;
- event time = proposal end;
- direction = LONG;
- coverage requires >=8 eligible proposal-events, >=4 unique token symbols, and >=4 independent Snapshot spaces.

The source corpus is the already archived 626-proposal 2023-2024 Snapshot universe mapped only through DeFiLlama governanceID-safe token identities.

## Final result

Mechanical classification:
- clean binary proposals: **43**
- positive wins: **41**
- negative wins: 2
- ties: 0
- positive-win assets: **LDO only**
- positive-win spaces: **1 (lido-snapshot.eth)**
- 2023: 24 positive wins
- 2024: 17 positive wins

The family fails cross-symbol coverage before production eligibility or price data: 41 events are all one token / one governance space.

Decision: **coverage blocked / freeze**. Binance USD-M age, QuoteVolume and post-event returns were not inspected. Do not treat many LDO proposals as cross-asset evidence, loosen the safe space mapping, or merge ambiguous Snapshot spaces to manufacture breadth.
