# Binance Auto-Invest Asset Addition → LONG — 2023-2024 Feasibility

Hypothesis: adding an existing cryptocurrency as an Auto-Invest investable asset opens a recurring-purchase channel and would be preregistered LONG.

Official 2023-2024 census:
- 13 Binance CMS titles mention Auto-Invest / Recurring Buy.
- After frozen exclusions for maintenance, payment options, competitions, UI changes and index-plan rebalancing, only one actual crypto-asset addition batch remains:
  2023-07-05 — MAV, PENDLE, WBETH, COMBO, IQ.
- FDUSD support is excluded as a stablecoin.

Raw coverage is therefore **5 events / 5 unique tokens**, below the preregistered minimum 8/8. Market eligibility and post-event returns were not read.

Decision: **coverage blocked / freeze**. Do not merge Earn, Convert, Spot listing, or payment-option events to manufacture sample size.
