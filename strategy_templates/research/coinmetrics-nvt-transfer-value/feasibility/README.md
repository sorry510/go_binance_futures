# CoinMetrics NVT / Transfer-Value Feasibility
CoinMetrics Community API requests for NVTAdj and TxTfrValAdjUSD returned HTTP 403 for the 10-symbol research universe, while TxCnt remained available. Therefore NVT/adjusted-transfer-value research is not reproducible with the current public data access.

Decision: data-access blocked; no paid/private data assumptions and no BTC/ETH-only special case.
