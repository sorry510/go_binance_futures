# Binance Futures Index Constituent / Weight Adjustment — Feasibility

Hypothesis: changes to USD-M index constituents or weights can mechanically change index composition and basis behavior.

The official Binance `Latest Binance News` catalog was exhaustively title-scanned across the 2023-2024 pages using fixed keywords `index price|constituent|weight|price index`. The historical slice returned zero mechanically identifiable candidate announcements.

Decision: coverage blocked before return inspection. Do not infer index changes from unrelated futures-update articles or manually curate a non-exhaustive event list.
