# DeFiLlama Protocol Value-Accrual Revenue — Feasibility

Hypothesis: protocol revenue or token-holder revenue is closer to direct token value accrual than gross fee activity and may provide a structurally distinct signal.

No returns were inspected.

Using the previously safety-mapped mature protocol-token universe, the free DeFiLlama fees summary endpoint was queried with dataType=dailyProtocolRevenue and dataType=dailyHoldersRevenue.

For 2023–2024, only LDO, ENS, and AXS had complete non-zero ProtocolRevenue history. LPT HoldersRevenue starts only in 2024-08 and supplies 139 non-zero discovery-period days. Most other mapped mature tokens either expose zero history, start in 2025+, or return no usable series.

Decision: coverage blocked (<8 mature symbols). Do not substitute gross fees, supply-side revenue, or late-start holder revenue; no discovery/OOS/exact replay.
