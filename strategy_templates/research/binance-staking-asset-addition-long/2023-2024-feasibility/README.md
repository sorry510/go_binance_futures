# Binance Legacy Staking Asset Addition → LONG — 2023-2024 Feasibility

Hypothesis: first support of an ordinary token on legacy Binance Staking / Locked Staking / DeFi Staking adds yield utility and therefore defines a preregistered LONG event.

The archived complete 2023-2024 Binance CMS corpus contains 19 titles with "staking".

Frozen semantic exclusions remove:
- ETH Staking generic withdrawal/product updates;
- NFT staking;
- Loan collateral articles that merely mention ETH staking rewards;
- removal notices;
- Simple Earn / VIP program updates;
- newer BNSOL/SOL liquid-staking and Babylon BTC On-chain Yields product lines, which are not the frozen legacy staking product definition.

Only **one** qualifying legacy token-level addition remains: **CVX**, from "Binance DeFi Staking Adds Support for CVX With Up to 19.8% APR" (2023-06-14).

## Final result

Raw coverage = **1 event / 1 token**, below the >=8/8 gate. Production eligibility, QV, and post-event returns were not read.

Decision: **coverage blocked / freeze**. Do not merge new liquid-staking/on-chain-yield products, ETH/NFT staking, Simple Earn, or APR promos to manufacture coverage.
