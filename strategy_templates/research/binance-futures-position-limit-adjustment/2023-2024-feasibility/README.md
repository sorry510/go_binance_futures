# Binance Futures Position-Limit Adjustment — 2023-2024 Feasibility

Hypothesis: contract-specific position-cap increases would be preregistered LONG and decreases SHORT because they change leverage capacity independently of price.

An exhaustive Binance official CMS 2023-2024 title audit found only one position-limit title: "Binance Futures Extends the Position Limit Adjustment Feature to COIN-M Contracts" (2023-05-15). It announces a platform feature, not contract-specific before/after position limits.

Qualifying token-level adjustment events: **0**. No market data or returns were read.

Decision: **coverage blocked / freeze**. Do not reinterpret leverage-tier/notional-bracket changes already studied as position-limit events.
