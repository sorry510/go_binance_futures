# Binance Network-Route Support Cessation → SHORT — Feasibility

Official 2023-2024 Binance announcements were audited for permanent cessation of token deposits/withdrawals on a named network while trading/other network routes remain available.

Auditable ordinary-token events:
- MAGIC via Ethereum
- DYDX via Ethereum
- One 2024-10-09 batch containing BETA, CREAM, LINA, IRIS, UNFI, HARD, CLV, PROS, VITE and OOKI

This gives **12 token-events / 12 unique tokens but only 3 independent article batches**.

The generic BNB Beacon Chain sunset announcement says "all BEP2 tokens" but does not provide a point-in-time token list and is excluded rather than reconstructed from current metadata. USDC/TRON is excluded as stablecoin.

The frozen coverage gate requires >=8 token-events, >=8 unique tokens and >=4 independent batches. It fails before USD-M eligibility, QV or any post-event return is read.

Decision: **coverage blocked / freeze**. Do not expand generic BEP2 language into a guessed historical token list, merge temporary maintenance, or lower the independent-batch gate. No DB import.
