# Protocol

1. Source is Binance official 2023-2024 announcement corpus.
2. Include only announcements that explicitly name ordinary crypto tokens whose deposit/withdrawal support on a specific network is being permanently ceased while the token remains available through other networks/trading.
3. Exclude stablecoins/fiat, generic network sunsets without a point-in-time token list, temporary maintenance/suspensions, and token migrations already covered by corporate-action research.
4. Direction is preregistered SHORT.
5. Coverage gate before any market eligibility/return read: >=8 token-events, >=8 unique tokens, >=4 independent article batches.
6. Generic BEP2 "all tokens" language cannot be expanded from a current or reconstructed list because that would introduce point-in-time ambiguity.
7. Failure freezes the family without reading any post-event return.
