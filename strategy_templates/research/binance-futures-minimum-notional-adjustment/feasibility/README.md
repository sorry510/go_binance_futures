# Binance USD-M Minimum Notional Adjustment — Feasibility

Hypothesis: changes to the minimum notional order value can alter retail accessibility and micro-liquidity for an existing perpetual contract.

The official Binance `Latest Binance News` archive was exhaustively title-scanned for 2023-2024. Only two USD-M minimum-notional announcements were found: BTCUSDT/ETHUSDT and LINKUSDT/BCHUSDT/ETCUSDT/LTCUSDT, for six unique contracts total. Spot/Margin minimum-order-size announcements were excluded as a different family.

Decision: coverage blocked before return inspection (<8 eligible event-symbols even before the >=2y/QV filters). Do not combine Spot/Margin order-size changes with Futures minimum-notional changes to inflate sample size.
