# Protocol

1. Use the already audited Binance official 2023-2024 title corpus; select titles beginning "Binance Completes Integration of".
2. Include only titles explicitly stating deposits are opened for the integration. This is a new token/network deposit-access expansion event.
3. Exclude Binance Web3 Wallet dApp integrations, stablecoin/fiat assets, and Mainnet-only titles that do not explicitly state deposits are opened.
4. Extract ticker from the official title. For multi-token titles, each ordinary crypto token is one token-event, but one article remains one independent batch.
5. Same token may have multiple events only when Binance adds a distinct network integration in a later independent article.
6. Direction is preregistered LONG: additional deposit/withdraw network support increases exchange accessibility and transfer-route availability for an already-listed token.
7. Before any post-event return is read, require same-name Binance USD-M history >=730 days at publish time and prior 24 complete 1h QuoteVolume >=5M USDT.
8. Coverage gate: >=8 eligible token-events, >=8 unique tokens and >=8 independent article batches.
9. Failure freezes before returns. Do not include stablecoins, Web3 Wallet dApps, mainnet-only ambiguous titles, or lower the production gates to manufacture coverage.
