# Binance Portfolio Margin Collateral-Asset Addition → LONG — 2023-2024 Feasibility

Hypothesis: adding an ordinary crypto token as a Binance Portfolio Margin collateral/margin asset expands institutional collateral utility and would define a preregistered LONG event.

The frozen Binance official CMS 2023-2024 corpus contains 1,071 titles. A broad Portfolio Margin / collateral-asset title audit returned 34 candidates, but almost all are collateral-ratio repricing, Loan/VIP Loan collateral additions, or generic Portfolio Margin program changes.

Only one title directly adds an asset to Portfolio Margin support: **2024-12-19 — “Binance Futures to Support BFUSD on Portfolio Margin Accounts.”** BFUSD is a stablecoin-like margin/reward asset rather than an ordinary crypto token with the target USD-M trading-history profile. Therefore qualifying ordinary-crypto token events = **0**.

The preregistered minimum coverage is 8 events / 8 unique tokens. Coverage fails before production eligibility or any post-event return is read.

Decision: **coverage blocked / freeze**. Do not merge collateral-ratio changes, Loan collateral additions, generic program expansions, or BFUSD-like margin units to manufacture a sample.
