# Protocol

1. Include only Binance-native announcements that add a specific ordinary crypto token as a newly supported Portfolio Margin collateral/margin asset.
2. Exclude collateral-ratio repricing, generic Portfolio Margin eligibility/program changes, Loan/VIP Loan collateral additions, and stablecoin/margin-unit products.
3. Direction would be LONG because new Portfolio Margin collateral utility expands institutional margin use.
4. Require >=8 events and >=8 unique ordinary-crypto tokens before production eligibility or return inspection.
5. Coverage failure freezes the family without merging Loan collateral or collateral-ratio events.
