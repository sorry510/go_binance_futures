# GitHub Core Release Catalyst — 2023–2024 Discovery

Hypothesis: a stable release of a token's canonical core-node/client repository is an externally timestamped protocol-delivery catalyst and should be followed by positive USD-M returns.

Events are GitHub Release objects only: draft=false, prerelease=false, published_at present. Same-symbol same-UTC-date releases are collapsed to the earliest publication. No tags/commits are substituted.

Direction is frozen LONG. Entry is the next complete Binance USD-M 1h open after publication. Eligibility requires >=2 years actual futures history and trailing complete 24h QuoteVolume >=5m USDT.

Frozen discovery gate: >=80 events, >=8 symbols, aggregate 12h mean >=+0.25%, >=60% symbols positive, and both 2023 and 2024 aggregate mean12 >0.

Discovery produced 257 events / 10 symbols. Aggregate 12h mean was +0.1364%; 7/10 symbols were positive. 2023 was +0.3607%, but 2024 was -0.0018%. The economic and cross-year gates failed.

Decision: freeze in discovery. OOS 2025-2026 remains return-untouched. No SHORT reversal, repository substitution, semver/title filtering, or exact TP8/SL6 replay.
