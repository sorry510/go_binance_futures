# Bitget Cross-Product Asset Exit -> Binance SHORT — 2025 Feasibility

This hypothesis was generated only after the 2023-2024 Bitget futures-only delist discovery failed breadth. It is therefore prohibited from validating itself on that old discovery.

Mechanism: an asset being removed from both Bitget spot and Bitget futures within the same operational delisting window represents an asset-level venue exit rather than derivatives-product pruning, and should be a stronger negative signal.

Frozen pre-return construction for the new hypothesis:
- new discovery would be 2025 only;
- 2026 would remain untouched OOS;
- same base token must appear in an official spot-delisting article and an official futures-delisting article whose publication timestamps are within 7 calendar days;
- signal time would be the later publication timestamp, because only then are both facts public;
- corporate-action / migration / rebrand cases would be excluded;
- minimum coverage before return inspection: 8 eligible events / 8 symbols.

Official Bitget Help Center pages covering all of 2025 contained 86 futures-delist candidate articles and 54 spot-delist articles. Spot article bodies were mechanically parsed for TOKEN/USDT and TOKEN/USDC pairs. Only one token matched the cross-product rule: HIFI, with the two publications about 146.3 hours apart.

Decision: feasibility/sample blocked before any 2025 return inspection. 2026 remains untouched. Do not widen the 7-day matching window or include futures-only events to create sample.
