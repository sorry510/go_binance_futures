# Snapshot Governance Value-Accrual - Feasibility
Snapshot public GraphQL is available. To avoid ticker impersonation/semantic contamination, spaces were mapped only through DeFiLlama protocol governanceID for mature uniquely mapped Binance tokens: LDO, ANKR, LRC, LINA, REN, GTC, APE and ENS. The complete 2023-2024 universe contains 626 proposals.

For causality the signal time was proposal creation, not the final vote result. A strict value-accrual phrase set (fee switch, token buyback/burn, revenue sharing, protocol fee distribution) in title or first 800 body characters produced only 6 events across 3 assets (LDO/LRC/APE). A separate strict emissions/inflation change family produced zero events. Expanding with Snapshot verified-space ticker alone was rejected because a verified third-party space can use another token as its voting unit.

Decision: feasibility blocked. No returns inspected.
