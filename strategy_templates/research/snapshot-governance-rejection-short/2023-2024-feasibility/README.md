# Snapshot Governance Rejection SHORT — Feasibility

Hypothesis: a clean binary governance proposal that closes with the explicit negative option winning is a protocol-governance failure/conflict event and may pressure the mapped token.

Source universe reuses the previously archived 626 Snapshot proposals from safely mapped DeFiLlama governanceID spaces. No price return was inspected for this family.

Mechanical classifier is intentionally strict: exactly two choices, with one clean positive label (For/Yes/Approve/Support) and one clean negative label (Against/No/Reject/No action/Oppose). Event time would be proposal end; direction would be SHORT only when the negative choice wins.

2023-2024 feasibility: 43 proposals matched the clean binary-choice grammar, but only 2 had the negative option win, and both were LDO in 2023. This is far below the minimum 8 events and has no cross-symbol breadth.

Decision: freeze before return inspection. Do not loosen to arbitrary opposition-share thresholds or include ambiguous choice semantics to manufacture sample size.
