# Protocol Funding Round / Strategic Investment — Feasibility

Hypothesis: externally announced protocol financing can change treasury runway, development capacity and perceived institutional sponsorship, creating a timestamped catalyst for a protocol token.

No returns were inspected.

DeFiLlama's raises dataset is manually maintained and its current API is behind the Pro/API-key surface. The public source repositories inspected do not expose a complete same-source historical raises database that can be mechanically reconstructed. A third-party static raises.csv found during feasibility covered only roughly 2024-04 through 2025-04, which is insufficient for a clean 2023-2024 discovery and later untouched OOS.

Decision: data-access/history blocked before returns. Do not use partial third-party snapshots or manually curated press searches to fabricate a complete event universe.
