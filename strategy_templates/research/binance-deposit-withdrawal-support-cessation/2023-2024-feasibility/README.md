# Binance Deposit/Withdrawal Network-Support Cessation — Feasibility

Hypothesis: an explicit Binance announcement permanently ceasing deposit/withdrawal support for an ordinary token/network route is a negative accessibility event (SHORT).

Strict title-level audit of the archived 2023-2024 Binance official corpus found 5 independent "Cease Support for Deposits and Withdrawals" articles:
- DYDX via Ethereum;
- BNB Beacon Chain (BEP2);
- tokens on selected networks;
- USDC via Tron;
- MAGIC via Ethereum.

The USDC-only batch is excluded before market data because stablecoins are not directional token events. Therefore the maximum possible ordinary-token independent-batch count is **4**, below the preregistered minimum of 5.

Decision: **coverage blocked before article-body parsing and before returns**. Do not merge generic network-upgrade suspensions, count USDC as a directional token, split one article into pseudo-batches, or lower the batch gate.
