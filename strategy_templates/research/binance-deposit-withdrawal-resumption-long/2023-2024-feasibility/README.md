# Binance Deposit/Withdrawal Resumption → LONG — 2023-2024 Feasibility

Hypothesis: an explicit Binance announcement confirming that token deposit/withdrawal access has been restored can restore transfer utility and arbitrage access; if coverage were sufficient the direction would be preregistered LONG.

The official Maintenance Updates catalogId=157 was exhaustively scanned for 2023-2024 titles containing resumption/reopen/restoration language together with deposit/withdrawal/network terms.

Only **one** explicit restoration announcement was found:
- 2023-05-29: TORN deposits resumed via Ethereum and BNB Smart Chain.

Planned network-upgrade notices that merely say deposits/withdrawals "will resume" automatically after maintenance are excluded because they are not confirmed restoration events.

## Final result

Raw coverage is **1 event / 1 token**, below the frozen minimum of 8/8. Production eligibility and post-event returns were not evaluated.

Decision: coverage blocked / freeze. Do not merge planned-upgrade announcements, generic wallet maintenance, or unrelated exchange resumption events to manufacture sample size.
