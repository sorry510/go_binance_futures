# Binance Borrow / Margin Interest-Rate Adjustment — 2023-2024 Feasibility

Hypothesis considered: token-specific borrowing-cost changes could alter the cost of borrowing/shorting and create a directional event signal.

Official-source coverage audit reused the frozen Binance CMS catalogId=49 2023-2024 corpus (1,071 titles). Search terms covered interest rate, hourly interest, borrowing rate, and loan rate.

Only one matching title exists: **2023-02-20 — “Binance Margin Introduces Dynamic Interest Rate Updates”**. It is a generic policy/mechanism announcement, not a token-level before/after interest-rate adjustment event. There is therefore no auditable cross-token event universe to test.

No production eligibility, market returns, or OOS data were read.

Decision: **coverage blocked / freeze**. Do not reconstruct historical token rates from current dynamic-rate rules, infer rate changes from generic policy text, or merge unrelated loan/margin additions into this family.
